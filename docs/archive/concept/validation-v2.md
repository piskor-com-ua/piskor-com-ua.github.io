# Перевірка концепту 02

12.09.2026. Локальний Chromium через Playwright.

- Пройдено 160 перевірок станів: 20 сцен × українська/англійська × 1440×1000, 390×844, 320×568, 844×390. Перевірено відповідність активного етапу й деталі, відсутність горизонтального переповнення, розміщення контактної дії й навігації у видимій області.
- Збережені знімки всіх етапів на ширинах 1440 і 390 для обох мов. Візуально перевірені модель, фасад, матеріали, мобільні пояснення та сценарії автоматизації. Виправлено положення позначок матеріалів і зображення закритих штор.
- Перехід «Напрями» веде на `#story`, початковий етап. Програмна навігація використовує миттєве переміщення сторінки; візуальний перехід відбувається всередині сцени.
- Світло: клавіші Home та ArrowRight встановили 5%; температура: End встановила 28 °C. Підписи керування доступні для вибору за назвою.
- Змінений стан автоматизації зберігся після переходу на архітектуру й повернення. Скидання відновило «Вдома».
- У режимі зменшеного руху відкрито всі п’ять етапів та їхні розгорнуті пояснення, кожне з чотирма деталями. Escape закриває діалог.
- Прокручування перевірено вперед і назад на проміжних положеннях 4.2 → 4.8 → 5.1 → 4.8 → 4.2. Активна деталь і змішування зображень відтворилися: opacity 0 → 0.58133 → 0 → 0.58133 → 0.
- Виявлені під час перевірки й виправлені проблеми: атрибут контейнера заважав активному стану кнопок; значення output потрапляло до доступної назви повзунка; панель автоматизації перекривала заголовок на 320×568.

Артефакти: `output/playwright/v2-*` (локально, не включаються до Git).

Це перевірка прототипу, не повний аудит WCAG або тест на фізичних пристроях. PageSpeed, Safari/Firefox, зовнішня публікація й реальне обладнання не перевірялися.

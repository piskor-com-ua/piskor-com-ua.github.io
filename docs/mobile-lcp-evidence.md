# Раннє завантаження мобільної обкладинки

Дата: 18.10.2026. База — main `aa8a8f2ecce16f1e23eb1a6c7ee954f0cb5e2fc9`. Початковий [production PSI](https://pagespeed.web.dev/analysis/https-piskor-com-ua-portfolio/ohj4t86bsg?form_factor=mobile): FCP/Speed Index 0,930 с, LCP 1,351 с, CLS/TBT 0, Agentic Browsing 5/5. Ціль LCP <1 с потребує окремого післярелізного вимірювання; наведені локальні результати її ще не підтверджують.

## Доставка першого екрана

- Збірка ставить адаптивний AVIF preload фактичної першої обкладинки після viewport перед шрифтами й SEO. Він використовує ті самі media, imagesrcset, imagesizes і версіоновані URL, що й picture/source. Немає фіксованої обкладинки чи розміру, паралельного preload WebP або запиту мобільного AVIF на desktop. Це охоплює обидві мови та всі річні каталоги.
- Згенеровані WOFF2 без legacy TrueType hinting: Light 17 344 → 12 508 B, Regular 17 260 → 12 404 B. Разом 34 604 → 24 912 B, −28,0%. Для всіх 174 символів кожного накреслення перевірено однакові контури й advance widths; GPOS/GSUB збігаються побайтово з попереднім піднабором. Вихідні WOFF2/TTF, ліцензія, накреслення й font-display swap збережені. Растеризація на інших платформах потребує звичайної перевірки читабельності.
- Статичний логотип у picture використовує lossless WebP 2 580 B замість PNG 5 861 B, з PNG fallback. Усі 216 216 RGBA-пікселів збігаються. Зменшення логотипа через Lanczos дало більші файли й не включене. Динамічна головна зберігає свій чинний PNG.
- Усі 2 007 наявних файлів assets поза папкою згенерованих піднаборів шрифтів залишилися побайтово незмінними, включно з обкладинками AVIF/WebP та вихідними фото. Контент, сітка, банер, згода на аналітику, noindex і WebMCP не змінені.

Сам preload у трьох початкових парних прогонах майже не змінив LCP. Експерименти з inline-зображеннями та синхронним decoding не дали потрібного результату й не включені. Вбудовування зображень збільшило HTML і погіршило швидкість.

## Локальне порівняння

Lighthouse 13.5.0, Chrome 155, стандартний mobile preset, холодні профілі, банер першого візиту, gzip через scripts/serve-benchmark.py. База завантажена з Linux-артефакту опублікованого main (run 39121055249), тому першою лишається та сама обкладинка Роксоляни. Кандидат застосовує до копії цього артефакту три наведені зміни доставки; його байти шрифтів і логотипа звірені з повною локальною збіркою. Перед запуском перевірено байти обох HTTP-серверів. Це порівняння без production HTTPS/CDN, а не PSI чи CrUX.

## Приймання релізу

Повна збірка: 18 Python-тестів, 113 HTML, 46 двомовних кейсів, 184 адаптивні картки, бюджет шрифтів 26 000 B. Браузерна перевірка: 276 поєднань кейсу/viewport, шість холодних перевірок вибору обкладинки на DPR 1/1,75/2 та межі 700 px — рівно один запит до currentSrc; окремо 10 сторінок на 390/1440 px, галерея/фокус, мови, контакти й стани аналітики. ARD і три схеми WebMCP перевіряються окремо. Локальний HTTP не доводить активації production Origin Trial.

Вибірка `scripts/release-sample.json` містить головну та EN-головну, обидва загальні каталоги, два річні каталоги й чотири різні кейси. Після публікації потрібні мобільні Lighthouse для всіх 10 URL, проходження меню головної обома мовами, п’ять холодних прогонів цільового каталогу, native WebMCP і новий PSI. Результати публікації додаються до PR після успішного CI та Pages.

Cloudflare змінюється лише після мерджу, Pages і перевірки нових ресурсів. Підготовлений порядок: короткий edge-кеш GET без query лише для `/portfolio/` та `/en/portfolio/`, origin max-age=600 і browser TTL origin; цільовий purge після deployment; MISS/HIT і свіжість HTML. Окремо можна порівняти Brotli → Gzip для HTML цих двох шляхів із поточним Zstandard: до релізу стиснений HTML був 25 993 B через Brotli та 27 604 B через Zstandard. Правило залишати тільки за підтвердженої користі. Решта HTML, discovery, дані, місячний кеш версіонованої статики й трекери зберігають чинну політику.

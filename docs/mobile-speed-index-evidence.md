# Раннє відображення мобільного каталогу

Дата: 16.10.2026. База — main db136b53d250229fd39ce1cf3043dff80e9f55b8 (опублікований PR #44). Ціль — Speed Index ≤1 с у холодному Mobile PSI / Slow 4G зі звичайним банером першого візиту. Локальний результат не є підтвердженням production PSI чи CrUX.

## Зміни

- Каталоги й річні архіви вбудовують невеликий catalog-bundle.css з тих самих спільних джерел і в тому самому порядку. Це повний bundle, а не окремий вручну підтримуваний набір стилів. URL вкладених ресурсів стають абсолютними після версіонування. Додаткові байти HTML обмінюються на відсутність блокуючого CSS-запиту; окремий bundle залишається доступним для попереднього HTML.
- Незмінений контролер analytics-consent.js виконується на початку body з тим самим measurement ID. Поява банера не чекає окремого JS-запиту. Логіка згоди, відмови, відкликання й завантаження GA4 залишається спільною; зовнішній файл збережено для попередніх сторінок.
- FontTools генерує WOFF2 з урахуванням усіх HTML/CSS/JS, HTML entities, Unicode/CSS escapes, повної української абетки та ASCII. Це охоплює також тексти галереї, банера, кнопок і помилок. Піднабори відтворювані, вихідні метрики гліфів збережені, оригінальні WOFF2/TTF і ліцензія залишаються доступними. Бюджет двох піднаборів — 40 000 байтів.
- Light: 55 436 → 17 344 B; Regular: 55 056 → 17 260 B. Разом: 110 492 → 34 604 B, економія 75 888 B (68,7%).
- Контент, сітка, порядок стилів, фотографії та інструменти агентів збережені. Cloudflare цим PR не змінюється; погоджений користувачем місячний browser TTL лишається чинним для версіонованої статики.

## Метод

Дві копії згенерованого артефакту, той самий комп’ютер, Lighthouse 13.5.0, холодний Chrome 155, стандартний mobile preset, відсутність збереженої згоди. Запуски чергуються main/зміни. П’ять парних прогонів, без паралельних Lighthouse-запусків. Обидві сторони однаково стискають текст gzip через scripts/serve-benchmark.py. Тут немає production HTTPS/CDN, тому вимірювання призначене для порівняння коду в однакових умовах.

Повторення:

```sh
python3 scripts/serve-benchmark.py BASELINE_ARTIFACT --port 4187
python3 scripts/serve-benchmark.py _site --port 4188
node scripts/benchmark-lighthouse.cjs http://127.0.0.1:4187/portfolio/ http://127.0.0.1:4188/portfolio/ --runs 5 --modes mobile --output output/speed-index-final
```

Сервери запускаються в окремих терміналах. Повні JSON і summary.json лежать у локальному ignored output/. Підсумки нижче — з фінальної збірки, включно зі звичайним логотипом PNG.

## Перевірки

- Збірка: регресійні тести, 112 HTML-сторінок, 46 двомовних кейсів, 184 картки; справжні розміри, srcset, пріоритет LCP, версії ресурсів, контраст і noindex.
- Регресійні тести перевіряють момент виконання consent, measurement ID, абсолютні URL inline CSS, динамічні й екрановані символи, метрики гліфів, відтворюваність і збереження оригінальних шрифтів.
- Нативний WebMCP у локальному Codex Browser: пошук 398 м²/2026, вісім англомовних секцій Замарстинівської та публічні контакти. Без надсилання повідомлень.
- Мобільний маршрут EN-кейс → галерея → ArrowRight → Escape → повернення фокуса → UA → контакти. Банер першого візиту видимий, GA4 до згоди відсутній.
- CI виконує всю матрицю 92 сторінок × 390/768/1440 px і стани згоди/відмови/відкликання через мережевий stub. Статус конкретного PR і deployment перевіряється окремо перед публікацією.

Після мерджу потрібні успішний Pages deployment, живі UA/EN ресурси та нові production PSI-вимірювання. SEO 69 очікується через збережений noindex. Результат агента 3/3 у Lighthouse не означає загальну підтримку WebMCP браузерами відвідувачів.
